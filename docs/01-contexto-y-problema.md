# Contexto y problema

## Contexto

La empresa distribuye agua mediante vendedores que visitan clientes de distintas comunidades. Parte de las operaciones se maneja mediante crédito y cobros en efectivo. El propietario necesita verificar que cada entrega, pago y liquidación haya quedado registrado correctamente.

## Problema central

El registro manual o disperso de clientes, créditos y pagos dificulta confirmar:

- dónde se encuentra cada cliente;
- qué producto fue entregado y si fue al contado o a crédito;
- cuánto dinero recibió cada vendedor;
- qué efectivo sigue pendiente de liquidar;
- si una operación fue modificada o anulada;
- qué clientes han reducido su frecuencia de compra.

Esto genera riesgo de errores, pérdida de información y posibles inconsistencias entre vendedores y administración.

## Propuesta

Waterline One registrará cada cliente en un mapa y cada movimiento con un folio único. Para pagos y entregas a crédito generará una constancia imprimible con código verificable. El sistema conservará una bitácora de cambios y permitirá al propietario conciliar el efectivo entregado por cada vendedor.

## Beneficiarios

| Actor | Beneficio |
|---|---|
| Propietario | Control de créditos, efectivo, liquidaciones y reportes. |
| Vendedor | Registro rápido, cliente localizado en mapa y constancia para entregar. |
| Cliente | Evidencia simple de su pago, abono o compra a crédito. |

## Resultado esperado

Mejorar el control verificable de las operaciones de campo y construir una base de datos confiable para futuros análisis de comportamiento y posible abandono de clientes.
